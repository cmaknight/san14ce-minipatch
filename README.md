# 삼국지14 CE Mini 패치

삼국지14 CE(Steam 한국어판 1.0.1)용 개인 제작 패치입니다. 게임 데이터 몇 곳을 고치고, 프록시 DLL(`dinput8.dll`)로 게임 코드의 일부 동작을 바꿉니다. 패처로 원하는 항목만 골라 적용하고, 언제든 원본으로 되돌릴 수 있습니다.

비공식 팬 제작물이며 KOEI TECMO GAMES와 관계가 없습니다.

## 패치 항목

| 번호 | 항목 | 내용 | 방식 |
| --- | --- | --- | --- |
| 1 | 숙련 모드 보강 | 부대능력 배율(50~200%) 설정 추가, 인접지역효과 최대치 2000%로, 무장경험획득 최소치 0% | DLL |
| 2 | 개성 조정 (새 게임 필요) | 구심·악주 효과 발동 시 저돌의 돌진 효과 무효, 저돌 공군 5%, 투장 포위 시 공군 10% 증가 | 데이터 + DLL |
| 3 | 페이즈 종료시 자동 탐색 | 자동탐색 설정 화면에 "자동진행" 행 추가. 켜 두면 페이즈 종료 때 남은 명령서로 탐색 자동 실행 | DLL |
| 4 | 개성·전법 툴팁 개선 | 정보 목록 등에서 개성·전법 툴팁 표시, 전법 효과 수치와 범위 표시 | DLL |
| 5 | 진형 밸런스 조정 | 학익 방어 30 → 36, 봉시 방어 18 → 20 | 데이터 |
| 6 | 로그 기능 보강 | 로그 창 드래그 높이 조절(4~19줄)과 휠 스크롤, 모든 세력 장수의 사망·이벤트 포로·직할 지역 내정 Lv 상승 로그 | DLL |
| 7 | 관직 임명 완화 | 이동 중이거나 임무 중인 장수도 관직 임명·교체·해임 가능(출진 장수 제외) | DLL |
| 8 | 훈련비 비례 차감 | 훈련비가 실제로 오른 사기만큼만 지출(AI 포함) | DLL |
| 9 | 내정 AI 개선 | AI 군주와 위임 군단이 상업·농업·병영 Lv을 균등하게 개발. 먼저 올리는 항목은 중시 설정, 없으면 군주·도독 성향을 따름 | DLL |

- 2번의 데이터 부분(개성 효과·설명문)은 새 게임부터 반영됩니다. 저돌 무효(DLL)는 진행 중인 세이브에도 적용됩니다.
- 1번 배율은 새 게임을 시작할 때 세이브에 기록됩니다. 패치 전에 만든 세이브는 100%로 동작합니다.
- 패치가 세이브에 쓰는 값은 원본 게임이 0으로 두는 칸만 씁니다. 패치를 지워도 세이브는 원본 게임에서 그대로 열립니다.

## 지원 버전

- Steam 공식 1.0.1(한국어 실행 파일 `SAN14CE_KO.exe`).
- 패처는 게임 파일 해시로 버전을 확인하고, 모르는 버전이나 이미 다른 도구로 수정된 파일이면 적용을 멈춥니다.
- DLL은 실행 파일의 빌드 정보와 패치 지점의 원래 바이트를 확인합니다. 게임이 업데이트되어 맞지 않으면 해당 기능을 적용하지 않고 게임은 원본대로 실행됩니다.
- 같은 파일을 고치는 다른 모드와는 함께 쓸 수 없습니다.

## 사용법

1. [Releases](../../releases)에서 `San14CE_MiniPatch_v<버전>.zip`을 받아 압축을 풉니다.
2. `San14CE_MiniPatch.exe`를 실행합니다(게임 폴더에 쓰기 위해 관리자 권한을 요청합니다).
3. 삼국지14 설치 폴더를 고르고([자동 찾기] 또는 [찾아보기…]), 적용할 항목을 선택한 뒤 [적용]을 누릅니다.
4. 되돌리려면 [원본 복구]를 누릅니다. 원본 파일은 게임 폴더의 `_san14patch/backup/`에 보관됩니다.

게임 폴더에 생기는 파일: `dinput8.dll`(DLL 항목을 하나라도 켰을 때), `san14patch.ini`(켠 항목), `_san14patch/`(백업과 상태). DLL의 설정값과 로그는 `%LOCALAPPDATA%\san14patch\`에 둡니다.

Steam에서 "게임 파일 무결성 확인"을 하거나 게임이 업데이트되면 데이터 항목이 원본으로 돌아갈 수 있습니다. 이때는 패처로 다시 적용하세요.

## 직접 빌드

필요한 것: Windows, Python 3(배포본은 3.14로 빌드), Visual Studio 2022 이상(MSVC x64, C 빌드 도구).

```bat
python -m venv .venv-build
.venv-build\Scripts\python -m pip install pyinstaller
tools\build_gui.cmd
```

결과: `dist\San14CE_MiniPatch_v<버전>.zip`. DLL만 빌드하려면 `src\dll\build.cmd`(결과 `out\dll\dinput8.dll`).

명령줄 패처:

```bat
python -m patcher groups
python -m patcher --game "<설치 폴더>" status
python -m patcher --game "<설치 폴더>" apply 1 2 3
python -m patcher --game "<설치 폴더>" restore
```

테스트: `python -m unittest`. 게임 파일이 필요한 테스트는 저장소 루트의 `game-copy/`(설치 폴더 사본)가 있을 때만 실행됩니다.

## 폴더 구조

| 경로 | 내용 |
| --- | --- |
| `patcher/` | 패처(엔진, GUI, CLI, 데이터 그룹, 압축·컨테이너 코덱, 원본 해시 표) |
| `src/dll/` | 프록시 DLL 소스. 기능별 `feat_*.c` |
| `tools/` | 배포본 빌드(`build_gui.cmd`)와 exe 진입점(`gui_main.py`) |
| `tests/` | 단위 테스트 |
| `docs/` | 구현 문서: 기능별 패치 지점, 게임 구조, 데이터 형식, 게임 업데이트 대응 |

구현 설명은 [docs/00-overview.md](docs/00-overview.md)부터 보세요.
